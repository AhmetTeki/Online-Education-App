# 🎓 Online Education Platformu (ASP.NET Core MVC + Web API - .NET 8)

Bu proje, **ASP.NET Core MVC** ve **Web API** kullanılarak geliştirilen bir online eğitim platformudur. Öğrenci, Eğitmen ve Admin olmak üzere üç farklı kullanıcı rolünü desteklemektedir. Eğitim süreçlerini dijital ortama taşımayı amaçlayan bu sistem, modern yazılım mimarilerine uygun olarak geliştirilmiştir.

---

## 🚀 Teknolojiler ve Araçlar

- ✅ .NET 8
- ✅ ASP.NET Core MVC
- ✅ ASP.NET Core Web API
- ✅ Entity Framework Core
- ✅ MSSQL Server
- ✅ AutoMapper
- ✅ N-Tier Architecture (Katmanlı Mimari)
- ✅ Bootstrap (veya Tailwind) – Frontend için

---

## 🧱 Katmanlar

### 1. 👨‍🎓 **Öğrenci (Student)**
- Kurslara kayıt olabilir
- Kayıtlı kurslarını görebilir
- Kullanıcı arayüzü üzerinden etkileşim sağlar

### 2. 👨‍🏫 **Eğitmen (Instructor)**
- Yeni kurs oluşturabilir
- Mevcut kursları güncelleyebilir
- Kendi kurslarına ait katılımcıları görebilir

### 3. 🛠 **Yönetici (Admin)**
- Kullanıcı yönetimi (Öğrenci / Eğitmen ekleme / silme)
- Kurs onaylama ve kontrol
- Genel sistem yönetimi
